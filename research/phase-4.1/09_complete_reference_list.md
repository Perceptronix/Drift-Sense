## E. Key Reference Summary

### Software Architecture (Primary)
- [S1] Bass et al. (2021) — The standard software architecture textbook. Architecture styles, quality attributes, design decisions.
- [S8] Martin (2017) — Clean Architecture. Layer separation, dependency rules, testing strategies.
- [S10] Buschmann et al. (1996) — Pattern-Oriented Software Architecture. Layered architecture pattern, pipeline pattern.

### Design Methodology
- [S5] Ousterhout (2018) — A Philosophy of Software Design. Module decomposition, information hiding, complexity reduction.
- [S9] Fowler, Beck (2018) — Refactoring. Data immutability, testing, evolutionary design.

### Python and Project Organization
- [S12] Deitel (2019) — Python for Programmers. Module organization, naming conventions.
- [S13] pyPA (2023) — Python packaging standards.
